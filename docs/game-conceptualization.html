Bomb Pass

Answer questions and pass the bomb. When time runs out, the holder gets a penalty. Last player standing wins.
Team: Bomb Pass Team (BSCS 3-2) Version: 1.0.0 Date: October 2026

1. Overview

Bomb Pass is a web-based multiplayer question game for the Library Game Hub. A host (librarian or teacher) logs in, creates a question set, and starts a session. The server generates a 6-digit join code. Players join with just a nickname Ã¢â‚¬â€ no account needed. Players answer multiple-choice questions while passing a virtual bomb to each other. When the bomb timer expires, the holder receives a penalty. At 3 penalties, a player is eliminated. The last active player wins.

The server is authoritative for all game state: it validates answers, tracks the bomb holder, manages the timer, and determines penalties. The client only displays state.

5. Mechanics

Host Mechanics

  • Log in with username + password (bcrypt-hashed)
  • Create, list, view, export, import, and copy question sets
  • Start a session (server generates the 6-digit join code)
  • End a running session
  • Review saved results after the game

Player Mechanics

  • Join with code + nickname (no account, no personal data)
  • View the active question and choices
  • Submit one answer per question
  • Pass the bomb to another active player
  • See penalty count and active/eliminated status
  • Leave the game (forfeit)
  • View the final leaderboard

6. Win / Lose Rules

Winning

  • The game ends when only one active player remains
  • That player is the winner

Losing

  • A player is eliminated after 3 penalties
  • A penalty is received when the bomb timer expires while holding the bomb

Tie-breaking: Not applicable Ã¢â‚¬â€ the game continues until one player remains.
