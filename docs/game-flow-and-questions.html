Step-by-step

1. Host logs inThe host (librarian/teacher) signs in with a username and password. The server returns a JWT token for all host actions.
2. Host creates a question setThe host builds a set of multiple-choice questions (2–4 choices each, or true/false). The server stores it and keeps the correct answer secret.
3. Host starts a sessionThe host picks a question set. The server generates a unique 6-digit join code (never starts with 0).
4. Players joinPlayers open the game, enter the 6-digit code, and pick a nickname (2–20 characters). No account needed. Each player gets a short-lived token for this session only.
5. Host starts the gameOnce at least 3 players have joined, the host starts the session. The server picks a random first bomb holder and starts the countdown timer.
6. Players answerThe server sends the current question. Each player submits one answer. The server checks it and returns {correct, score, rank} — never the correct answer.
7. Bomb holder passesThe player holding the bomb passes it to another active player. The timer resets. Only the current holder can pass.
8. Bomb explodesWhen the timer reaches zero, the bomb "explodes." The server gives the holder 1 penalty. At 3 penalties, that player is eliminated.
9. RepeatSteps 6–8 repeat. The server advances to the next question after each explosion (or once everyone has answered).
10. WinWhen only one active player remains, the game ends. That player is the winner. The server saves the final leaderboard.
